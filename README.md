# Sistema BI (Laravel + Tabler + Tailwind CSS)

Aplicação web desenvolvida em Laravel para gestão de painéis de Business Intelligence (BI) e controle de acessos corporativos, utilizando o template de design **Tabler** combinado com **Tailwind CSS**.

---

## 🚀 Funcionalidades Principais

* **Painel Administrativo & Dashboard**: Visão geral e indicadores do sistema.
* **Gestão de Acessos**: Controle completo de Usuários, Perfis (`Roles`) e Permissões.
* **Layout Responsivo & Retrátil**: Barra lateral (sidebar) dinâmica com suporte a estado colapsado (recolhida/expandida) e persistência de preferência no navegador.
* **Ícones Modernos**: Integração com *Tabler Icons*.

---

## 🛠️ Tecnologias Utilizadas

* **[Laravel](https://laravel.com/)** (v13+)
* **[Tailwind CSS](https://tailwindcss.com/)**
* **[Tabler UI / Tabler Icons](https://tabler.io/)**
* **Vite** (para empacotamento de assets)
* **Blade Templates**

---
